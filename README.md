# Photography Portfolio

Static portfolio site prepared for GitHub Pages.

## Personalize before publishing

- In `index.html`, replace every `Your Name` with your name.
- Change `hello@example.com` to your email address.
- Change the Instagram link in the footer.

## Publish with GitHub Pages

1. Create an empty GitHub repository, for example `portfolio`.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In the repository, go to **Settings → Pages**.
4. Set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Your site will be available at `https://YOUR-USERNAME.github.io/portfolio/`.

For the cleanest URL, name the repository `YOUR-USERNAME.github.io`; the homepage will then be `https://YOUR-USERNAME.github.io/`.
